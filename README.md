# ¿Crecer o quebrar? El papel del endeudamiento en la rentabilidad de las empresas ecuatorianas

## Autores
José Ordóñez, Lisbeth Jiménez y Adriana Guerrero.

## Institución
Universidad Nacional de Loja - Carrera de Economía.

## Descripción
Esta investigación analiza la relación entre el endeudamiento y la rentabilidad de las empresas ecuatorianas durante 2024.

## Fuente de información
Superintendencia de Compañías, Valores y Seguros del Ecuador.

## Metodología
Análisis descriptivo, sectorial y econométrico mediante R y RStudio.

## Herramientas
R, RStudio, Quarto y GitHub.

## Estado
Investigación académica en desarrollo.
